# 🗺️ معجم الأنساب والبلدان (MAP-DINHK)
### المنصة الرقمية الشاملة لأمهات كتب البلدان والأنساب الخمسة (36,775 مادة تراثية بنسبة 100% و625 حاضرة على الخريطة)

منصة جغرافية وتراثية إلكترونية متطورة تعتمد الخرائط التفاعلية والذكاء البحثي لاستيعاب كامل نصوص أمهات المصادر الجغرافية والأنسابية في الحضارة الإسلامية.

---

## 🌟 أمهات المصادر الخمسة المستوعبة كاملة (36,775 مادة 100%)

1. **معجم البلدان** للإمام شهاب الدين ياقوت الحموي الرومي (ت 626هـ): استيعاب كامل لـ **12,358 موضعاً وبلداً** ونهراً وجبلاً وقرية بنصوصه الأصلية الكاملة.
2. **مراصد الاطلاع على أسماء الأمكنة والبقاع** لصفي الدين عبد المؤمن البغدادي (ت 739هـ): **11,642 مادة** تمثل تهذيباً وتحريراً وضبطاً لغوياً وجغرافياً دقيقاً لمعجم البلدان بحروف المعجم.
3. **معجم ما استُعجِم من أسماء البلاد والمواضع** لأبي عبيد البكري الأندلسي (ت 487هـ): **3,750 مادة** جغرافية متخصصة في جزيرة العرب وأشعار العرب ومواضع السيرة والحديث النبوي.
4. **كتاب الأنساب** للإمام الحافظ أبي سعد السمعاني المروزي (ت 562هـ): استيعاب كامل لـ **4,442 نسبة** بنصوصه الأصلية وتراجم رواته ومحدثيه وأعلامه.
5. **اللباب في تهذيب الأنساب** لعز الدين ابن الأثير الجزري (ت 630هـ): **4,583 نسبة** تستدرك وتهذب كتاب الأنساب للسمعاني.

## 🗺️ الخريطة التاريخية التفاعلية (625 حاضرة وموضعاً)
- **625 حاضرة وبلداً وقرية وثغراً تاريخياً** محققاً بالكامل مع الإحداثيات والضبط التام بالشكل والتوثيق من أمهات المصادر.
- **التوسعة الإفريقية الكبرى (25 حاضرة تاريخية)**: تمبكتو، غانة، جني، غاو، تكرور، كانم، كانو، أودغشت، ولاتة، دنقلة، سوبا، سواكن، باضع، سنار، زيلع، مقديشو، هرر، براوة، النجاشي، كلوة، زنجبار، ممباسا، صوفالة الذهب.
- **تغطية طرق القوافل والحج الكبرى**: درب زبيدة الكوفي، طريق الحج الشامي والمصري والساحلي واليمني.
- **التعريب الكامل لخريطة الأساس** وطبقة فلسطين العربية التاريخية بمدنها وقراها الأصيلة.
- **محرك التثبيت المكاني O(1)** مع زر "📍 عرض على الخريطة" لكافة مواد الموسوعة.

5. **تجريد أسماء الأعلام من ألقاب التفخيم**:
   - اعتماد المنهجية التراثية الصارمة بعرض أسماء الأعلام مجردة من ألقاب التفخيم والمشيخة لضمان الحيادية الموسوعية الرصينة.

6. **أدوات تراثية ملحقة**:
   - **حاسبة المسالك والفراسخ**: قياس المسافات التاريخية بالفراسخ والمراحل وأيام السير مع رسم المسار على الخريطة.
   - **أطلس الأقاليم الإسلامية الكبرى**: استعراض أقاليم العالم الإسلامي وتصفية الحواضر.
   - **تحدي ومسابقة الأنساب والبلدان**: مسابقة تفاعلية في ضبط أنساب البلدان والصنائع وأعلامها.
   - **أنساب الصنائع والمهن والقبائل**: قسم مخصص للأنساب غير المكانية (المعدل، الكاتب، الوراق، الخزاز...).

## 🚀 التشغيل والتطوير والنشر السحابي (Production & Deployment)

> 📖 **للاطلاع على دليل التثبيت الشامل خطوة بخطوة، راجع: [INSTALL.md](file:///e:/موقع%20البلدان/INSTALL.md)**

### المواصفات البيئية المدعومة
* **نظام التشغيل الخادم**: Ubuntu 24.04 LTS
* **بيئة الحاويات**: Docker + Coolify + Traefik + Cloudflare Tunnel
* **إصدار Node.js**: `Node.js 24.19.0 LTS` (`node:24.19.0-bookworm-slim`)
* **المنفذ الداخلي (Internal Port)**: `3000` (`HOST=0.0.0.0`)
* **نقطة فحص الصحة (Health Check)**: `GET /health` تعيد HTTP 200 `{"status":"ok"}`
* **إدارة الإغلاق الآمن**: التعامل السلس مع إشارات `SIGTERM` و `SIGINT`
* **محركات البحث و SEO**: خريطة موقع قياسية `sitemap.xml` وملف `robots.txt` وبيانات منظمة Schema.org وبطاقات Open Graph.

### أوامر التطوير والإنتاج السريع
```bash
# تثبيت الحزم التزامني الحتمي
npm ci

# تشغيل خادم التطوير المحلي
npm run dev

# بناء الحزمة الإنتاجية
npm run build

# تشغيل خادم الإنتاج (Port 3000)
npm start

# التشغيل بنقرة واحدة عبر Docker Compose
docker compose up -d
```

### النشر عبر Docker و Coolify
المستودع مهيأ بالكامل للنشر التلقائي عبر Coolify باستخدام `Dockerfile` متعدد المراحل (Multi-stage build):
1. **Stage 1 (deps)**: تثبيت الحزم بنسخها المقفلة `package-lock.json`.
2. **Stage 2 (builder)**: بناء أصول الموقع وحزم الموسوعة الشاملة في `dist/`.
3. **Stage 3 (runner)**: تشغيل خادم إنتاج فائق السرعة عبر المستخدم الآمن غير الجذري `USER node` على المنفذ `3000`.
