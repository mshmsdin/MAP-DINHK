# 🗺️ معجم الأنساب والبلدان (MAP-DINHK)
### المنصة الرقمية الشاملة لكتابي «معجم البلدان» لياقوت الحموي و«الأنساب» للإمام السمعاني (100% استيعاب كامل)

منصة جغرافية وتراثية إلكترونية متطورة تعتمد الخرائط التفاعلية والذكاء البحثي لاستيعاب كامل مواد وتراجم التراث الجغرافي والأنسابي الإسلامي.

---

## 🌟 أبرز الميزات والمحتويات

1. **الاستيعاب الكامل 100% للكتابين (16,800 مادة تراثية كاملة)**:
   - **معجم البلدان** للإمام شهاب الدين ياقوت الحموي الرومي (ت 626هـ): استيعاب كامل لـ **12,358 موضعاً وبلداً** ونهراً وجبلاً وقرية بنصوصه الأصلية الكاملة (طبعة دار صادر ببيروت).
   - **كتاب الأنساب** للإمام الحافظ أبي سعد عبد الكريم بن محمد السمعاني المروزي (ت 562هـ): استيعاب كامل لـ **4,442 مادة نسب** بنصوصه الأصلية الكاملة وتراجم رواته ومحدثيه (طبعة دائرة المعارف العثمانية بتحقيق المعلمي اليماني).

2. **المستكشف الموسوعي الشامل**:
   - نافذة استكشاف تتيح تصفح مواد الكتابين أبجدياً عبر حروف الهجاء الـ 28 كافة، مع تصفية وبحث داخلي فائق السرعة.

3. **قارئ النصوص التراثية الفاخر (Corpus Reader)**:
   - عرض النص التراثي الأصلي كاملاً بنسبة 100%.
   - النطق الصوتي التراثي للعنوان عبر تقنية التركيب الصوتي.
   - **الربط التبادلي التلقائي (Cross-Referencing)**: يربط آلياً بين موضع البلدة في معجم البلدان ونسبتها في كتاب الأنساب للسمعاني، والعكس بالعكس.
   - أدوات تكبير وتصغير الخط ونسخ النص الموثق مع الإحالة بنقرة واحدة.

4. **خريطة الأساس العربية الأصيلة**:
   - خريطة تفاعلية كاملة معربة الأسماء (OpenStreetMap) تبرز كافة الدول والمدن والعواصم والمسطحات المائية باللغة العربية الفصحى، مع إمكانية التبديل بين 4 أنماط (الخريطة العربية، القمر الصناعي، التضاريس، النمط الليلي).

5. **تجريد أسماء الأعلام من ألقاب التفخيم**:
   - اعتماد المنهجية التراثية الصارمة بعرض أسماء الأعلام مجردة من ألقاب التفخيم والمشيخة لضمان الحيادية الموسوعية الرصينة.

6. **أدوات تراثية ملحقة**:
   - **حاسبة المسالك والفراسخ**: قياس المسافات التاريخية بالفراسخ والمراحل وأيام السير مع رسم المسار على الخريطة.
   - **أطلس الأقاليم الإسلامية الكبرى**: استعراض أقاليم العالم الإسلامي وتصفية الحواضر.
   - **تحدي ومسابقة الأنساب والبلدان**: مسابقة تفاعلية في ضبط أنساب البلدان والصنائع وأعلامها.
   - **أنساب الصنائع والمهن والقبائل**: قسم مخصص للأنساب غير المكانية (المعدل، الكاتب، الوراق، الخزاز...).

## 🚀 التشغيل والتطوير والنشر السحابي (Production & Deployment)

### المواصفات البيئية المدعومة
* **نظام التشغيل الخادم**: Ubuntu 24.04 LTS
* **بيئة الحاويات**: Docker + Coolify + Traefik + Cloudflare Tunnel
* **إصدار Node.js**: `Node.js 24.19.0 LTS` (`node:24.19.0-bookworm-slim`)
* **المنفذ الداخلي (Internal Port)**: `3000` (`HOST=0.0.0.0`)
* **نقطة فحص الصحة (Health Check)**: `GET /health` تعيد HTTP 200 `{"status":"ok"}`
* **إدارة الإغلاق الآمن**: التعامل السلس مع إشارات `SIGTERM` و `SIGINT`

### أوامر التطوير والإنتاج
```bash
# تثبيت الحزم التزامني الحتمي
npm ci

# تشغيل خادم التطوير المحلي
npm run dev

# بناء الحزمة الإنتاجية
npm run build

# تشغيل خادم الإنتاج (Port 3000)
npm start
```

### النشر عبر Docker و Coolify
المستودع مهيأ بالكامل للنشر التلقائي عبر Coolify باستخدام `Dockerfile` متعدد المراحل (Multi-stage build):
1. **Stage 1 (deps)**: تثبيت الحزم بنسخها المقفلة `package-lock.json`.
2. **Stage 2 (builder)**: بناء أصول الموقع وحزم الموسوعة الشاملة في `dist/`.
3. **Stage 3 (runner)**: تشغيل خادم إنتاج فائق السرعة عبر المستخدم الآمن غير الجذري `USER node` على المنفذ `3000`.
